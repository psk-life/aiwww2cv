# Конвертер резюме (Flask)

Веб-приложение для конвертации резюме: загрузка файла `.pdf` / `.txt` / `.md`,
распознавание разделов, переформатирование в один из 8 стилей для
международных площадок и скачивание результата в форматах `.txt`, `.md`,
`.json`, `.html`.

## Запуск

```bash
pip install -r requirements.txt
python app.py          # http://127.0.0.1:5000
```

Порт задаётся переменной окружения `PORT`.

## Как это работает

1. **Загрузка** — файл (до 5 МБ) принимается в формате .pdf, .txt или .md.
2. **Парсер** (`parser.py`) находит разделы (ФИО, должность, контакты,
   опыт, образование, навыки, языки, курсы, достижения, портфолио,
   дополнительно), извлекает ФИО, телефоны, email, telegram/skype, ссылки.
3. **Промежуточный JSON** — распознанная структура сохраняется во временный
   файл `temp/<id>/<id>_input.json` (хранится 2 часа, потом удаляется).
4. **Стиль** (`styles.py`) — переформатирование в выбранный стиль
   (`temp/<id>/<id>_styled.json`).
5. **Выходные файлы** — `.txt`, `.md`, `.json`, `.html`; кнопки скачивания
   активируются по готовности.

## Стили (8)

| Стиль | Сайт | Особенности |
|---|---|---|
| LinkedIn Modern | LinkedIn | headline + about, навыки первыми |
| Xing Klassik | Xing | классическая европейская структура |
| hh.ru Профиль | hh.ru | карточка hh.ru: навыки, позиция |
| Indeed ATS | Indeed | «плоский» текст для ATS-систем |
| Glassdoor Insight | Glassdoor | акцент на достижениях и саммари |
| Europass EU | Europass | стандарт ЕС, языки отдельным блоком |
| Monster Career | Monster | полный формат с портфолио |
| **A4 One-Pager (12 pt / 1,5)** | Универсальный печатный | **строго 1 страница A4/Legal, 12 pt, межстрочный интервал 1,5 — только ФИО, контакты и последняя актуальная информация** |

## Технологии и требования

- **Шрифты**: Inter (SIL OFL, бесплатна для коммерции) / DejaVu Sans.
- **Палитра** (контраст AA на тёмном фоне): `#0E1117`, `#7D8BFF`, `#57D6C2`, `#F2B544`.
- **W3C/WCAG**: `lang="ru"`, семантика `header`/`nav`/`main`/`section`/`article`/`footer`,
  иерархия заголовков, `aria-pressed` на переключателе стилей, видимый фокус
  (`:focus-visible`), skip-link, `prefers-reduced-motion`.
- **Адаптив**: mobile-first, сетка `repeat(auto-fit, minmax(...))`,
  типографика на `clamp()`, `env(safe-area-inset-*)` для iPhone;
  диапазоны 360–430 px, 768–1024 px, 1366–2560 px.

## Структура проекта

```
app.py            # Flask-маршруты: /, /download/<cid>/<fname>
parser.py         # парсинг резюме (.txt/.md/.pdf)
styles.py         # определения стилей
renderers.py      # сборка styled JSON + рендеринг txt/md/json/html
templates/        # index.html
static/style.css  # стили сайта
temp/             # временные файлы конвертаций (автоочистка 2 ч)
```
